# JS Sprite Animations

Interactive canvas sprite animations built with JavaScript.

## Live Demo

View the live gallery at: [https://osalotioman.github.io/js-sprite](https://osalotioman.github.io/js-sprite)

## About

This project is a collection of sprite animations created using HTML5 Canvas and vanilla JavaScript. Each animation demonstrates different techniques for working with sprite sheets and game development concepts.

## Animations

### Shadow Dog
Interactive dog sprite featuring 10 different animation states:
- Idle
- Jump
- Fall
- Run
- Dizzy
- Sit
- Roll
- Bite
- KO
- Get Hit

## What You'll Learn

Working through this project teaches:
- Sprite sheet manipulation and frame extraction
- Frame-based animation techniques
- HTML5 Canvas API usage
- Animation state management
- Game loop implementation
- Interactive controls and user input

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Osalotioman/js-sprite.git
```

2. Open `index.html` in your browser to see the gallery, or navigate directly to any animation folder.

## Project Structure

```
js-sprite/
├── index.html          # Main gallery page
├── assets/
│   ├── img/           # Sprite sheets
│   └── aud/           # Audio files
└── dog/               # Shadow Dog animation
    ├── index.html
    ├── script.js
    └── style.css
```
